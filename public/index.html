Настройки фабрики

Сохраняются между запусками

При достижении указанного остатка или ниже фабрика приостанавливает обращения к Codex и сохраняет незавершённую работу. Возобновление — после подтверждённого восстановления лимита. Локальные проверки продолжаются. 0 отключает резерв.

Лимит общий для аккаунта. Данные приходят с задержкой, поэтому точный остаток в момент остановки может быть меньше порога.

По умолчанию раз в сутки. Сводка строится локально по новым завершённым запускам. Для активного проекта создаётся одна задача анализа; она соблюдает резерв лимита. Предложенные изменения проходят проверки и отдельное ревью.
